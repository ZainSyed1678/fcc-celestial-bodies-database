# Celestial Bodies Database

A PostgreSQL relational database project completed as part of the freeCodeCamp Relational Database Certification.

## Overview

The database models celestial objects and their relationships, including galaxies, stars, planets, moons, and planet types.

## Technologies Used
- PostgreSQL
- SQL
- psql

## Database Structure

- `galaxy`
- `star`
- `planet`
- `moon`
- `planet_types`

## Concepts Practiced

- Relational database design
- Primary and foreign keys
- One-to-many relationships
- SERIAL auto-incrementing columns
- UNIQUE and NOT NULL constraints
- Data types: INT, NUMERIC, TEXT, BOOLEAN, VARCHAR
- SQL INSERT statements

## How to Restore

```bash
psql -U postgres < universe.sql
```
